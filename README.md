# 🎵 Artist Verse

A responsive artist discovery app built with vanilla HTML, CSS & JavaScript. Search and explore your favourite Bollywood, Punjabi, and Haryanvi artists — click any card to view their bio and popular songs.

## ✨ Features

* **Artist Cards:** Browse a curated collection of 45+ popular Indian artists with photos and clean card-based UI.
* **Live Search:** Filter artists instantly as you type — no page reload.
* **Interactive Popup:** Click any card to open a detailed modal showing the artist's bio and top songs.
* **Smooth Dismiss:** Close the popup via the ✕ button or by clicking the backdrop.
* **Gradient Overlay:** Text stays readable on every card regardless of the photo.
* **Fully Responsive:** Adapts cleanly across desktop and mobile screens.

## 🛠️ Tech Stack

* **HTML5** — Semantic structure
* **CSS3** — Flexbox, Grid, pseudo-elements, transitions, and media queries
* **JavaScript (ES6+)** — DOM manipulation, event handling, and live search filtering

## 🚀 How to Use

1. Browse the artist cards on the homepage
2. Use the search bar to filter by name in real time
3. Click any card to view the artist's bio and popular songs
4. Click ✕ or outside the popup to close it
